# Como testar o novo site da Prefeitura

**Para:** servidores da Prefeitura de Jeriquara que vão avaliar o novo site antes de ele entrar no ar.
**De:** SECKE Sistemas.

## O que é este ambiente
É uma **versão de teste** do novo site, com o conteúdo do site atual já transferido (notícias, documentos, licitações, páginas). Ele **não aparece no Google** e pode ser usado à vontade: nada do que for feito aqui afeta o site atual. As cores e o brasão ainda são provisórios.

| | Endereço |
|---|---|
| **Site (o que o cidadão vê)** | https://portal-municipal-homologacao.portal-municipal.workers.dev |
| **Painel (onde a prefeitura publica)** | https://painel-municipal-homologacao.portal-municipal.workers.dev |

Para entrar no painel, cada pessoa recebe da SECKE um link de convite para criar a própria senha. Peça o seu informando nome, e-mail e o que vai fazer (escrever, publicar ou administrar).

## O que conferir no site (15 minutos)
Marque o que conferiu. Anote qualquer coisa estranha, com o endereço da página.

- [ ] **Notícias:** procure 3 notícias que você conhece. O texto, as fotos e a data estão certos?
- [ ] **Licitações e documentos:** procure 3 licitações ou decretos recentes. Os arquivos anexados abrem?
- [ ] **Páginas da Prefeitura:** "A Prefeitura", "Departamentos", "O Município". Os textos estão atualizados (nomes, telefones, responsáveis)?
- [ ] **Busca:** pesquise algo que o cidadão costuma procurar (ex.: "IPTU", "concurso", "vacina").
- [ ] **Endereços antigos:** abra um link salvo do site atual trocando o começo do endereço (`https://www.jeriquara.sp.gov.br`) pelo do site de teste. Deve abrir a página certa.
- [ ] **No celular:** abra o site de teste no celular e navegue um pouco.
- [ ] **Acessibilidade:** experimente os botões **A+** e **Alto contraste** no topo.
- [ ] **Rodapé:** endereço, telefone, e-mail e horário de atendimento estão certos?

## O que conferir no painel (para quem vai publicar)
- [ ] Entrar com o seu acesso.
- [ ] Criar uma notícia de teste com uma foto, publicar e ver se aparece no site (pode levar até 1 minuto).
- [ ] Apagar a notícia de teste.
- [ ] Ver a lista de **Documentos e legislação** e abrir um item.

## Como mandar as observações
Envie para a SECKE (pelo e-mail combinado na reunião) uma lista simples assim:

| Página (endereço) | O que está errado ou faltando | Como deveria ser |
|---|---|---|
| | | |

Prazo combinado para o retorno: ____/____/______

**Quem está testando pela Prefeitura:** ______________________________________
